# CareLens Healthcare Readmission Dashboard

## Run on Windows
1. Extract this ZIP folder.
2. Open the extracted folder.
3. Click the File Explorer address bar, type `cmd`, and press Enter.
4. Run:
   `python -m pip install -r requirements.txt`
5. Run:
   `python -m streamlit run app.py`
6. Upload `diabetic_data.csv` in the dashboard sidebar.

The app uses Plotly for interactive charts and a Logistic Regression educational demo.
This is not a clinically validated decision-support system.
